# COMP 3123 Lab 11 — Working with Axios and Fetch API

Fitsum Asgedom · 101510623

## Run locally

Use Node.js 22.12 or newer.

```powershell
npm ci
npm start
```

Open the local URL printed by Vite. The app loads 10 profiles from Random User with Axios on startup. Select **Fetch API** to load 10 profiles using the browser's Fetch API. Use **Details** to view a profile's ID, nationality, and time zone offset.

Run `npm run build` to check the production build.
